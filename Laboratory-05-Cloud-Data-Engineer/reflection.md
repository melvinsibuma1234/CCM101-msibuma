# Mission Reflection

## What I Learned

In this laboratory activity, I learned about Block Storage, File Storage, and Object Storage. I learned that Object Storage is useful for storing large amounts of unstructured data such as photos, videos, and backups.

## MinIO Deployment Experience

I learned how to deploy MinIO using Docker in a Linux environment. I also learned how to access the MinIO Web Console through port 9001 and create an object storage bucket.

## Challenges Encountered

One challenge I encountered was accessing the MinIO Web Console and understanding how ports 9000 and 9001 are used. I also encountered an issue with the MinIO Client installation, so I used the MinIO Web Console to manage the storage.

## Key Takeaway

My main takeaway from this laboratory is that Object Storage provides a practical way to store and manage unstructured data. I also gained hands-on experience deploying a storage service with Docker and managing objects using MinIO.
