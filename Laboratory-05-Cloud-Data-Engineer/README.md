# Laboratory 05 - Cloud Data Engineer

## Mission Overview

In this laboratory activity, I will deploy an S3-compatible object storage server using MinIO and Docker. I will create a storage bucket, upload a test file, and document the cloud storage operations.

## Objectives

* Understand the differences between Block Storage, File Storage, and Object Storage.
* Deploy MinIO using Docker.
* Access the MinIO Web Console using port forwarding.
* Create an object storage bucket and upload a file.
* Document the deployment and storage operations using Markdown.

## Tools Used

* KillerCoda Playground
* Docker
* MinIO
* GitHub
* Web Browser
* Ubuntu/Linux command line

## Skills Learned

* Understanding different types of cloud storage.
* Deploying a cloud storage service using Docker.
* Using Linux command-line commands.
* Accessing a cloud service through a web port.
* Creating buckets and uploading objects in MinIO.
* Documenting cloud computing activities using Markdown.
