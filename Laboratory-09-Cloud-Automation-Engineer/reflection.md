# Mission 9 Reflection: The Cloud Automation Engineer

Automation is important when managing hundreds of cloud servers because performing the same tasks manually takes time and increases the possibility of human error. With automation, administrators can execute repetitive tasks consistently and efficiently. For example, a backup script can save application data at scheduled times without requiring someone to remember to run the command manually.

However, automation also has potential dangers. If a script contains a destructive command or an incorrect file path, it may delete or modify important data. When the same faulty script is scheduled to run on 1,000 servers, the damage could affect many systems at once. This is why scripts should be reviewed, tested in a safe environment, and monitored before being deployed on a large scale.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. A Bash script contains shell commands that execute sequentially to perform tasks such as creating directories and compressing files. Docker Compose YAML, on the other hand, describes the configuration of services, containers, networks, and volumes. Both are useful automation tools, but they serve different purposes.

Reviewing my GitHub portfolio from Laboratory 1 to Laboratory 9 helped me recognize how my understanding of cloud computing has developed. I learned about cloud infrastructure, deployment, operations, security, and automation. Each activity introduced practical skills that contribute to managing cloud environments more effectively.

Among the roles I explored, I particularly enjoyed the Cloud Security Engineer role because it taught me how to protect systems by configuring firewall rules and limiting unnecessary network access. I also found cloud automation valuable because it reduces repetitive work and improves consistency. Overall, this mission taught me that automation is powerful when combined with careful testing, proper permissions, monitoring, and responsible system administration.
