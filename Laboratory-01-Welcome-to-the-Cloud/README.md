# Laboratory 01 – Welcome to the Cloud

## Mission Overview
This laboratory activity introduced me to the Linux environment and basic cloud computing tasks. I used the KillerCoda Playground to work with Ubuntu Linux and prepared my Cloud Computing portfolio.

## Objectives
- Access and use a cloud-based Linux environment.
- Explore and navigate Linux.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Document technical work using Markdown.
- Create and maintain a GitHub repository.

## Activities Performed
- Accessed the Ubuntu Linux Playground using KillerCoda.
- Created and logged in to the `msibuma` user account.
- Checked the username, working directory, and hostname.
- Gathered Linux system information.
- Created and organized Markdown files and directories.
- Created a GitHub repository for the Cloud Computing portfolio.

## Skills Learned
I learned how to work in a Linux environment, use basic Linux commands, organize files and directories, document technical information using Markdown, and prepare a GitHub portfolio.
