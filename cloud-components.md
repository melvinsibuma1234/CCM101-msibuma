# Cloud Infrastructure Components

## 1. Compute Resources

**Purpose:**  
Compute resources provide the processing power needed to run applications, services, and workloads in a cloud environment.

**Importance in Cloud Computing:**  
Compute resources are important because they allow users to run programs and applications without needing to maintain physical servers.

**Relation to the Linux Environment:**  
In the KillerCoda Linux environment, the CPU and its available cores provide the computing power used to execute commands and run applications.

---

## 2. Storage Resources

**Purpose:**  
Storage resources are used to store operating system files, applications, user data, and other information.

**Importance in Cloud Computing:**  
Storage is important because cloud applications need a reliable place to save and access data.

**Relation to the Linux Environment:**  
The Linux environment uses its disk storage to store system files, applications, and other data. The available storage can be examined using Linux commands such as `lsblk` and `df -h`.

---

## 3. Networking Resources

**Purpose:**  
Networking resources allow computers and cloud services to communicate with each other and exchange data.

**Importance in Cloud Computing:**  
Networking is important because cloud resources need network connectivity to communicate with users, applications, and other services.

**Relation to the Linux Environment:**  
The KillerCoda Linux server uses a network interface and an IP address to communicate over the network.

---

## 4. Operating System

**Purpose:**  
The operating system manages the computer's hardware and provides an environment for running applications and commands.

**Importance in Cloud Computing:**  
An operating system is important because cloud servers need software that manages their resources and allows applications and users to interact with the system.

**Relation to the Linux Environment:**  
The KillerCoda environment provides a Linux operating system that allows users to execute commands, investigate system resources, and perform cloud infrastructure tasks.
