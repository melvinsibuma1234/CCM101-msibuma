# Cloud Provider Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Virtual Private Cloud (VPC) |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID | Cloud Identity and IAM |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.

Amazon Web Services (AWS) offers a very broad range of cloud services. It provides services for computing, storage, networking, databases, security, and many other cloud requirements.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

Microsoft Azure would be a suitable choice because it integrates well with Microsoft products and services. Organizations already using Microsoft technologies may find Azure easier to integrate into their existing environment.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform is widely recognized for its capabilities in Artificial Intelligence, Machine Learning, and Kubernetes services.

### 4. What similarities did you observe among the three cloud providers?

All three cloud providers offer similar core infrastructure services, including compute, storage, networking, and identity and access management. They provide cloud resources that can be accessed and managed through their respective platforms.
