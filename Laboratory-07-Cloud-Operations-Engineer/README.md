# Laboratory 07 – Cloud Operations Engineer

## Mission Overview

In this laboratory activity, I will perform cloud operations tasks by monitoring a Linux server, deploying a containerized Nginx web server, generating web traffic, analyzing application logs, and monitoring container performance.

## Objectives

- Monitor CPU, memory, and disk resources.
- Deploy and monitor a web container.
- Generate web traffic and analyze application logs.
- Monitor container CPU, memory, and network usage.
- Document the results using Markdown.

## Monitoring Commands Executed

- `free -h`
- `df -h`
- `top`
- `docker logs client-website`
- `docker stats`
- `curl`

## Skills Learned

- Linux system monitoring
- Docker container management
- Application log analysis
- Container performance monitoring
- Technical documentation using Markdown
