# System Baseline Report

## Memory

The host server was checked using the `free -h` command.

- Total RAM Available on the Server: **1.9 GiB**
- Used Memory: **451 MiB**
- Free Memory: **949 MiB**
- Available Memory: **1.4 GiB**
- Swap: **1.0 GiB**

## Disk Storage

The host server's disk capacity was checked using the `df -h` command.

- Root File System: `/dev/vda1`
- Total Storage Capacity of Root (/): **19G**
- Used Storage: **5.6G**
- Available Storage: **13G**
- Storage Usage: **31%**

## Why Disk Space Is Critical

Checking disk space is critical before a massive traffic surge because increased traffic can generate additional logs and data, and insufficient disk space can affect the server's ability to operate properly.
