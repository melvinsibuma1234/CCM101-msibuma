# Microsoft Azure Research

## 1. Brief Overview

Microsoft Azure is a cloud computing platform that provides services for computing, storage, networking, databases, security, analytics, and application development.

## 2. Global Infrastructure

Azure provides a global cloud infrastructure organized into regions and availability zones. This allows organizations to deploy applications and services in different geographic locations.

## 3. Cloud Management Console

The Azure portal is a web-based management interface used to create, configure, monitor, and manage Azure resources and services.

## 4. Four (4) Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtualized computing resources that allow users to run applications and operating systems in the cloud.

### 2. Azure Blob Storage

Azure Blob Storage provides scalable object storage for documents, media files, backups, and other unstructured data.

### 3. Azure Virtual Network

Azure Virtual Network allows organizations to create private network environments and connect Azure resources securely.

### 4. Microsoft Entra ID

Microsoft Entra ID provides identity and access management for users, applications, and resources.

## 5. Three (3) Advantages

### 1. Microsoft Integration

Azure provides strong integration with Microsoft products and technologies such as Windows Server, Microsoft 365, and Active Directory.

### 2. Global Infrastructure

Azure provides cloud infrastructure across many geographic locations, supporting applications used by organizations around the world.

### 3. Enterprise Capabilities

Azure offers a wide range of services for enterprise computing, storage, networking, databases, security, analytics, and application development.

## 6. Typical Enterprise Use Cases

Azure is commonly used by enterprises for:

* Windows Server workloads
* Microsoft 365 integration
* Application hosting
* Database management
* Data analytics
* Identity and access management
* Enterprise cloud migration
