# Google Cloud Platform (GCP) Research

## 1. Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform that provides services for computing, storage, networking, databases, artificial intelligence, machine learning, and application development.

## 2. Global Infrastructure

Google Cloud provides a global infrastructure organized into regions and zones. This infrastructure allows organizations to deploy applications and services in different geographic locations.

## 3. Cloud Management Console

The Google Cloud Console is a web-based interface used to create, configure, monitor, and manage Google Cloud resources and services.

## 4. Four (4) Core Services

### 1. Compute Engine

Google Compute Engine provides virtual machines that can be used to run applications and workloads in the cloud.

### 2. Cloud Storage

Google Cloud Storage provides scalable object storage for files, backups, media, and other types of data.

### 3. Virtual Private Cloud (VPC)

Google Cloud VPC provides networking capabilities that allow users to create and manage virtual networks for cloud resources.

### 4. Cloud Identity

Cloud Identity provides identity and access management capabilities for users and organizations.

## 5. Three (3) Advantages

### 1. Artificial Intelligence and Machine Learning

GCP provides strong tools and services for developing and deploying artificial intelligence and machine learning applications.

### 2. Kubernetes Support

Google Cloud provides strong support for Kubernetes through Google Kubernetes Engine (GKE).

### 3. Global Infrastructure

Google Cloud provides infrastructure in multiple regions and zones, allowing organizations to deploy applications globally.

## 6. Typical Enterprise Use Cases

GCP is commonly used by enterprises for:

* Artificial Intelligence and Machine Learning
* Data analytics
* Application hosting
* Website and mobile application development
* Cloud storage and backup
* Kubernetes deployments
* Large-scale data processing
