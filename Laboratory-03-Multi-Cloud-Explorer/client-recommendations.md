# Client Recommendations

## Client A – Startup Company

### Recommended Platform: Amazon Web Services (AWS)

AWS is recommended for the startup because it provides a wide range of cloud services that can support a mobile application and future growth. Its scalable infrastructure allows the company to increase resources as the number of users grows. AWS also provides services that can help the startup manage computing, storage, and databases.

### Recommended Services

* Amazon EC2 – Compute resources for applications
* Amazon S3 – Storage for application files and data
* Amazon RDS – Managed relational database

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is recommended because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, making cloud migration easier. The university can use Azure services while maintaining compatibility with its current Microsoft environment.

### Recommended Services

* Azure Virtual Machines – Cloud-based Windows Server workloads
* Microsoft Entra ID – Identity and access management
* Azure SQL Database – Managed database service

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

Google Cloud Platform is recommended for the AI research company because of its strong focus on Artificial Intelligence and Machine Learning. GCP provides cloud services that can support high-performance computing and AI workloads. It also provides tools for developing, training, and deploying machine learning applications.

### Recommended Services

* Compute Engine – Virtual machines for high-performance workloads
* Google Kubernetes Engine (GKE) – Kubernetes container management
* Vertex AI – AI and machine learning platform

---

## Client D – Global E-Commerce Company

### Recommended Platform: Amazon Web Services (AWS)

AWS is recommended for the global e-commerce company because it provides scalable and highly available cloud infrastructure. Its global infrastructure can support customers in different geographic locations. AWS services can also help the company handle changing traffic and maintain reliable online operations.

### Recommended Services

* Amazon EC2 – Scalable application computing
* Amazon S3 – Object storage
* Amazon RDS – Managed relational database

---
