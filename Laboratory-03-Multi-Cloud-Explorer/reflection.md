# Mission Reflection

## Reflection

Completing the Multi-Cloud Explorer laboratory helped me understand the similarities and differences among AWS, Microsoft Azure, and Google Cloud Platform. Each cloud provider offers important services for computing, storage, networking, identity management, databases, and application development. Although their services may have different names, they provide similar solutions for many common cloud requirements.

The cloud platform that impressed me the most was Amazon Web Services (AWS). I found AWS interesting because of its wide range of services and its ability to support different types of organizations. It can provide solutions for startups, enterprises, application hosting, storage, databases, networking, and many other workloads.

AWS, Azure, and GCP have several similarities. All three provide virtual machines, object storage, networking services, identity management, databases, and Kubernetes solutions. They also provide global infrastructure that allows organizations to deploy applications and services in different geographic locations.

Business requirements are important when selecting a cloud platform because different organizations have different needs, budgets, technologies, and workloads. For example, Azure is a strong choice for organizations already using Microsoft technologies, while GCP can be suitable for AI, machine learning, and Kubernetes workloads. AWS can be useful when an organization needs a broad selection of cloud services and scalability.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. The decision should be based on the client's technical requirements, existing environment, budget, scalability needs, and business goals.

This laboratory also improved my GitHub Cloud Computing Portfolio by adding organized documentation, cloud research, comparison tables, recommendations, and evidence screenshots. Overall, the activity helped me better understand how cloud platforms can be evaluated and matched to real-world business requirements.
