# Laboratory 03 – Multi-Cloud Explorer

## Mission Overview

This laboratory activity focuses on exploring and comparing three major cloud platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

The activity aims to understand the core services, advantages, infrastructure, and use cases of each cloud provider. It also involves analyzing different business scenarios and recommending the most suitable cloud platform based on specific requirements.

## Cloud Platforms

* Amazon Web Services (AWS)
* Microsoft Azure
* Google Cloud Platform (GCP)

## Laboratory Checkpoints

### Checkpoint 1 – Expand Your Cloud Portfolio

Created the `Laboratory-03-Multi-Cloud-Explorer` folder and organized the required files and screenshots.

### Checkpoint 2 – Explore the Three Cloud Platforms

Research will cover:

* AWS
* Microsoft Azure
* Google Cloud Platform

Each platform will be documented based on its overview, global infrastructure, management console, core services, advantages, and enterprise use cases.

### Checkpoint 3 – Compare the Major Cloud Platforms

The three cloud platforms will be compared based on their:

* Launch year
* Compute services
* Storage services
* Networking services
* Identity services
* Primary strengths
* Ideal organizations

### Checkpoint 4 – Cloud Platform Recommendation Challenge

Different business scenarios will be analyzed to determine which cloud provider best meets each client's requirements.

### Checkpoint 5 – Match the Cloud Services

Equivalent services from AWS, Azure, and GCP will be identified and compared.

### Checkpoint 6 – Multi-Cloud Decision Matrix

A decision matrix will be created to recommend suitable cloud providers for different business requirements.
