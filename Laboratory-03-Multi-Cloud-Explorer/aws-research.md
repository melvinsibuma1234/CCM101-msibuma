# AWS Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of services for computing, storage, networking, databases, security, and other cloud workloads.

## 2. Global Infrastructure

AWS operates a global cloud infrastructure consisting of geographic Regions and Availability Zones. This infrastructure allows organizations to deploy applications and services in different locations around the world.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can create, configure, monitor, and manage cloud resources through the console.

## 4. Four (4) Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can be used to run applications and workloads in the cloud.

### 2. Amazon S3

Amazon Simple Storage Service (S3) provides scalable object storage for files, data, backups, and other digital content.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create and manage a private network environment for AWS resources.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls access to AWS resources by managing users, roles, and permissions.

## 5. Three (3) Advantages

### 1. Scalability

AWS allows businesses to scale computing resources up or down depending on their needs.

### 2. Global Availability

AWS provides cloud infrastructure across many geographic regions, allowing organizations to deploy applications closer to their users.

### 3. Wide Range of Services

AWS offers a broad selection of cloud services for computing, storage, networking, databases, security, and other workloads.

## 6. Typical Enterprise Use Cases

AWS is commonly used by enterprises for:

* Web and mobile application hosting
* Data storage and backup
* Database management
* Business analytics
* Disaster recovery
* Scalable enterprise applications
