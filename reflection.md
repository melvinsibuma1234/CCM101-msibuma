# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think compute resources are one of the most important cloud infrastructure components because they provide the processing power needed to run applications and services. Without compute resources, cloud applications would not be able to process tasks or respond to users.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable and flexible operating system for cloud servers. It also provides many commands and tools that allow engineers to monitor, manage, and investigate system resources.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it helps engineers understand the resources, configuration, and design of an infrastructure before deployment. It also makes it easier to identify problems, explain design decisions, and maintain the system.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux cloud environment using different terminal commands. I also learned how to identify compute, storage, networking, and operating system resources and document them using Markdown.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio improved because I added a structured laboratory project containing technical documentation, cloud provider comparisons, infrastructure information, and a cloud architecture diagram. This makes my portfolio more organized and demonstrates my developing cloud computing skills.
