# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focuses on understanding the basic components of cloud infrastructure. The activity involves investigating a Linux cloud server, identifying compute, storage, networking, and operating system resources, comparing major cloud providers, and designing a simple cloud infrastructure.

## Objectives

- Explain the major components of cloud infrastructure.
- Investigate hardware and software resources in a Linux environment.
- Differentiate compute, storage, networking, and identity resources.
- Understand the relationship between cloud infrastructure components.
- Create technical documentation using Markdown.
- Build a structured GitHub Cloud Computing Portfolio.

## Cloud Infrastructure Components

The main infrastructure components investigated in this laboratory are compute, storage, networking, and the operating system. These components work together to provide the resources needed to operate applications and services in a cloud environment.

## Linux Commands Executed

The following Linux commands were used to investigate the cloud server:

- `cat /etc/os-release`
- `uname -r`
- `lscpu`
- `nproc`
- `free -h`
- `lsblk`
- `df -h`
- `hostname`
- `hostname -I`

## Skills Learned

Through this laboratory activity, I learned how to investigate a Linux server and identify its basic infrastructure resources. I also learned how to document technical information using Markdown and compare equivalent services from different cloud providers.

## Challenges Encountered

One challenge was understanding the different cloud infrastructure components and how they relate to a Linux environment. Another challenge was using Linux commands correctly and organizing the laboratory files according to the required repository structure.
